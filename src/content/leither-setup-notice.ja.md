# dTweet コミュニティからのお知らせ

dTweet コミュニティは、ユーザーが提供するハードウェアと帯域幅によって支えられています。登録ユーザーは共有リソースを使って、オリジナルの投稿を最大5件公開できます。それ以上投稿するには、自分の投稿を保存・配信するノードを設置してください。

以下は基本的な配信ノードの設定手順です。

1. Linux、macOS、または Windows を実行するサーバーを用意します。

2. 参加するサーバーを1つのクラウドサービスに統合する Leither をインストールします：https://github.com/cfa532/Leither/blob/main/README_EN.md
    Leither の既定のポートは4800です。dTweet コミュニティでは8000より大きいポート番号を推奨しています。

3. Leither のインストールディレクトリで以下のコマンドを実行し、dTweet サーバーアプリを自分のサーバーに同期します。
    ./Leither mimei sync heWgeGkeBX2gaENbIBS_Iy1mdTS

4. https://github.com/cfa532/TweetWeb から `tus-server` のコードを取得し、サーバーにアップロードしてサービスとして実行します。`tus-server` の `.env` ファイルの既定値は `port=8081` です。適切なポートを選び、ファイアウォールで許可してください。このポートがプロフィールの `cloudDrivePort` になります。設定が完了すると、自分のハードウェアと帯域幅を使って、件数の制限なく投稿を公開できます。
